# 🔍 Lost and Found Management System

A PHP and MySQL-based web application designed to help institutions, campuses, or organizations track, report, and manage lost and found items efficiently.

---

## 🌟 Key Features

### 👤 User & Faculty Interface
* **Report Lost Items (`lost_post.php`):** Users can submit details and descriptions of items they have lost.
* **Report Found Items (`found_post.php`):** Users can upload details of items they have found.
* **Browse & View Posts (`lost_show.php`, `found_show.php`, `faculty_show.php`):** Easily view active listings of lost and found items.
* **User Authentication (`login.php`, `register.php`):** Secure login and account registration system.

### 🔑 Admin Management
* **Admin Dashboard (`admin_home.php`):** Overview of application activities and listings.
* **Post Management (`admin_manage_posts.php`):** Administrators can approve, edit, or delete reported listings.
* **System Statistics (`stats.php`):** Insights into total lost, found, and resolved items.
